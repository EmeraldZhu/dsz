## inFAMOUS Second Son port (Castlesea, shadPS4-based): DSZ-side findings

Session 2026-11-07 01:07–01:11 UTC. Port-side issues are tracked in the port's own audit; this lists only what DSZ shows.

| # | Symptom | What DSZ's log / files show | Owner |
|---|---|---|---|
| P1 | Launcher menus (dev and normal) see no controller | `inFAMOUS Second Son Launcher (dev).exe` reads pads only through XInput (imports `XInputGetState`; no HID, SDL, GameInput or DirectInput). A DSZ rule sends it to the "DualSense" profile, and DSZ's helper Xbox pad is hidden from games, so no XInput pad exists for it | Port: add a DualSense path (SDL/HID) to the launcher. DSZ workaround: rule launcher → "Xbox" profile |
| P2 | Haptics feel muted | The game sends **classic rumble** (`heavy 0, light 90`), never opens the virtual DualSense's sound device, so there are no haptic waveforms. Expected for a PS4 title: it was made for DualShock 4 motors. Only the light motor was driven, which renders as a faint buzz | Port: rumble scaling/mapping. DSZ: raise Haptics → "Haptic rumble strength" |
| P3 | Sounds expected on the controller speaker play on PC speakers | The game never opened the virtual DualSense's sound device, so all audio goes to the Windows default output | Port: route the PS4 pad-speaker stream to the controller's audio endpoint |
